# SparkIIT Internship Projects
**Author:** Prachurya Saikia

## Project 1: Inventory & Order Management Application
A Python application built with object-oriented programming. It manages products, customers and orders, updates stock automatically, validates input, handles errors with custom exceptions, saves data to JSON and CSV, and generates inventory reports and order summaries.

Notebook: `Inventory_App/`

## Project 2: Business Data Analysis & Reporting System
A pandas-based workflow that cleans a messy sales dataset, then filters, sorts and aggregates it, runs statistical analysis, draws charts (bar, line, pie, histogram, heatmap) and generates an automated text report. The reusable `run_pipeline()` function processes any similar CSV in one call.

Notebook: `Business_Analysis/`

## How to run
1. Install the libraries: `pip install pandas numpy matplotlib seaborn openpyxl jupyter`
2. Open a notebook in VS Code or Jupyter.
3. Choose Restart, then Run All. The notebooks create their own data files, so no downloads are needed.
